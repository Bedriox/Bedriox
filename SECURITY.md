# Security policy

Security fixes target the latest published Bedriox release and the current `main` and `development` branches. Older releases are unsupported; upgrade before requesting a backport.

Do not disclose suspected vulnerabilities in public issues. Report them to [security@bedriox.com](mailto:security@bedriox.com) or through GitHub private vulnerability reporting. Reports may cover Bedriox, Protocol, NetherNet, Gateway, and official Bedriox tools.

Include the affected version or revision, security impact, minimal reproduction steps or proof, and any known mitigation. Do not include live credentials or unrelated personal information. We aim to acknowledge complete reports within three business days and coordinate public disclosure after a fix is available.
