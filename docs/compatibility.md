# Compatibility

| Component | Current policy |
|---|---|
| PHP | 64-bit PHP `^8.4` (8.4 through 8.x, excluding PHP 9) |
| Operating systems | Windows x86-64 and Linux x86-64 development targets |
| Bedrock clients | Minecraft Bedrock 1.26.50 and 1.26.51 |
| Network protocol | 2193 |
| Bedriox API | Pre-alpha and unstable |

Protocol support will always list exact retail client versions and network protocol numbers. Preview clients are unsupported unless explicitly stated.

[`bedriox.lock.json`](../bedriox.lock.json) is the machine-readable integration manifest and records the exact compatible component revisions.
